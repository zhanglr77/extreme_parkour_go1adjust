## 使用场景选择

### 使用标准配置（go1_config.py）：
✅ 间隙 >10cm  
✅ 已有训练好的模型  
✅ GPU显存有限（<20GB）  
✅ 快速验证流程  

### 使用高分辨率配置（go1_gap_highres_config.py）：
✅ 间隙 <10cm（特别是2-5cm）  
✅ 从头训练新模型  
✅ GPU显存充足（>24GB）  
✅ 为视觉蒸馏准备高质量teacher  

## 重要提醒

⚠️ **两个配置的模型不兼容！**

```
❌ 不能：用标准配置训练 → 用高分辨率配置play
❌ 不能：用高分辨率配置训练 → 用标准配置play

✅ 必须：训练和评估使用同一配置
✅ 如果切换配置：必须从头训练
```
